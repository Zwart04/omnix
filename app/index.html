    Welcome to Omnix
    
        
    One small workbench for the way agents actually work:
          a terminal, a worktree, a browser, and the sessions you already have.
    
        
      
          
    • One window. Terminals, projects, split panes, and agent
            history live together instead of in ten tabs.
      • 
          
    • On demand. Plugins and the agent browser start when you
            call them, then stop. No background daemon.
      • 
          
    • Yours. Local-first, GPL-3.0, and no account required.
      • 
        
    
      
    

      
    
        
    Open a project
    
        
    Pick the folder you want to work in. Omnix remembers it
          in the sidebar and can start your first terminal there.
    
        
        
    
          
          
        
    
        
    Optional. You can skip this and add projects later from
          the sidebar.
    
        
    
      
    

      
    
        
    Choose your agents
    
        
    Omnix launches the CLI agents already installed on this
          machine. Leave an agent off if you do not use it.
    
        
    
        
    
      
    

      
    
        
    You are set
    
        
    Open a terminal with Ctrl `, split
          the pane with Ctrl Shift D, or press
          Ctrl K for every command.
    
        
    
          
    Ctrl KCommand palette
    
          
    Ctrl Shift DSplit terminal
    
          
    Ctrl `New terminal
